# Windows 1.2.44 release verification - 29 October 2026

Application and package source: `d3bb80a0469647a20e49d6094312658893956002` in `blazespark221-byte/cadence`, branch `fix/annotate-images-windows`, based on Windows 1.2.43. Build and acceptance: https://github.com/blazespark221-byte/cadence/actions/runs/40813782587 (attempt 2; attempt 1 stopped before any build when the runner timed out downloading the pinned Swift toolchain).

This release lets Annotate see pictures. The circled area of the frozen screen is encoded on this PC as a JPEG (at most 1568 pixels on its long side) and sent to Cadence Chat as an image beside the words Windows text recognition reads there, so a photo, chart, diagram or screenshot with no words is answered instead of refused. Annotate conversations, follow-ups included, always ask the managed service for Swift (`cadence-chat`, GPT-6 Luna), whatever model is chosen for Chat. The shared Swift engine sends the picture as an `image_url` part only to providers that accept images, and the bridge accepts a PNG or JPEG of at most 2 MB per circled area. Saved chats keep pictures for the newest 30 Annotate conversations. A Chat window left open on another virtual desktop is moved to the current one before it is shown. Translate is unchanged and sends only the circled words. The managed service accepts pictures from cadence-api version `36e3fd60`, deployed before this release.

Both the Windows shell and Swift bridge were built fresh from clean source on an isolated Windows x64 runner. The package includes matching .NET Desktop/Swift runtimes and the self-contained background worker. The downloaded ZIP and installer match the build's SHA-256 manifest; 529 payload files were independently verified against build-manifest.json.
