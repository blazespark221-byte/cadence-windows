# Cadence for Windows 1.2.44: Annotate sees what you circle

- **Annotate sees pictures:** circle a photo, chart, diagram, drawing or screenshot as well as text, and Cadence answers about it. Before, Annotate only read the words in the circled area, so a picture without words was refused with "couldn’t find any text". The circled area is now sent to Cadence as a picture, together with the words Windows reads from it on your PC. Nothing else on your screen is sent. Follow-up questions in the same chat can see the picture too.
- **Annotate always answers with Swift,** whatever model you’ve chosen for Chat.
- If a Chat window was left open on another virtual desktop, Annotate’s answer brings it to the desktop you’re on instead of switching desktops.
- Translate is unchanged: it still reads the words in the circled area on your PC and sends only those words.
- Includes all features from 1.2.43.

Includes the required runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for exact checks and remaining limits.
