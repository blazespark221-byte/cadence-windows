Windows 1.0.7 fixes silent in-app update failures:

- A confirmed update that cannot start now shows an error dialog with the actual reason.
- Missing Windows installation registration explains how to repair the installed copy without losing settings or sign-in.
- The sidebar preserves the specific failure instead of replacing it with an unrelated settings/recording notice.
- Choosing No leaves the downloaded update ready without reporting a failure.

Requires Windows 10 build 19041+ on Intel/AMD x64. This release is unsigned. See RELEASE-VERIFICATION.md for exact checks and limits.
