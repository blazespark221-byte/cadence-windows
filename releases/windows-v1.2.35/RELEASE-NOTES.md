# Cadence for Windows 1.2.35 — Styles

- **Write the way you text different people.** Make a style for each group you write to, such as friends, your partner, family or work, and paste in a few messages you've sent them. While a style is in use, what you dictate is rewritten in that voice: the same tone, length, punctuation, emoji and slang, and everything you said kept. Off goes back to your cleanup level.
- **Switch in one click.** Hover the notch: the new Style row under Cleanup lists Off and every style. The tray menu has the same choice, and the dictation popup names the style while you speak.
- **Styles page.** The main window has a new Styles page to add, edit and delete styles. Start from Friends, Partner, Family or Work, add tone notes if you like, and up to 20 example messages per style.
- A styled dictation counts as one writing request, like cleanup. Your example messages stay on this PC and are sent only with your dictations.
- Includes everything from 1.2.34.

Includes the required .NET and Swift runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for the exact automated Windows checks and remaining limits.
