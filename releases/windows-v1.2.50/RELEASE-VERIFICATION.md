# Windows 1.2.50 release verification - 5 November 2026

Application and package source: `d2fc337cffe7ba5d8b2e078eb7d3289787fe0b98` in `blazespark221-byte/cadence`, branch `release/windows-1.2.50`, based on Windows 1.2.49 (`b09a5da0`). Build and acceptance: https://github.com/blazespark221-byte/cadence/actions/runs/42018469504 (attempt 1, source unmodified). Exact candidate stored in the private draft release `windows-candidate-1.2.50-42018469504`.

This release moves dictation from the on-device Parakeet model to Cadence's managed speech service. Dictation streams the recording while the person speaks over the restored live connection (`/v1/audio/transcriptions/stream`, with WaveInRecorder's PcmAvailable/CaptureDrained events back); spoken Refine instructions, Ask Cadence and kept recordings use the completed upload. The service (cadence-api 9392be15, deployed 5 November 2026) transcribes both with ElevenLabs Scribe v2 Realtime through Vercel AI Gateway. Parakeet's recognizer, decoder, model service, Settings section, on-device usage reports and licence are removed; its pinned downloader stays for S1-mini, which now starts without waiting for it. The old model folder (%LOCALAPPDATA%\Cadence\Models\parakeet-tdt-0.6b-v3) is deleted at launch. The spoken-language picker lists the service's 93 languages, the same list as Mac 0.3.44 (65).

Both the Windows shell and Swift bridge were built fresh from clean source on an isolated Windows x64 runner. The package includes matching .NET Desktop/Swift runtimes and Microsoft.ML.OnnxRuntimeGenAI 0.18.0 (with the licences for S1-mini and ONNX Runtime GenAI). The downloaded ZIP and installer match the build's SHA-256 manifest; 530 payload files are recorded in build-manifest.json. No application source or customer credentials are included in the public release.

Checks on this revision: 1889 managed-account checks; 116 portable parity checks (the Parakeet checks are replaced by checks for the language list, no dictionary upload and the old-model removal); 1429 CadenceCore checks on a Mac (Mac 0.3.44 source).

Windows application acceptance: 243 logic/controller checks (0 failures; 1 separate desktop suite skipped), 8 Annotate offscreen, 12 Chrome/Edge dictation, 5 opaque-editor, 11 native shortcut and 10 clipboard checks. Exact-package checks: 4 headless gates (including the offscreen UI check that the Dictation page has no speech-model section and offers the 93 languages), 7 floating-control checks, and 16 isolated installer/lifecycle gates, including upgrade from 1.0.4, restart/reinstall, synthetic settings/encrypted-session retention, uninstall and updater handoffs. Verification installers use a separate identity and temporary profiles; the production installation is not changed by these checks.

Earlier CI runs of this release: run 42012835791 stopped on the new offscreen check because the Dictation page subtitle still said "Speech model" (fixed); run 42015348839 passed, but its packaged VERIFICATION.md still described on-device Parakeet dictation (fixed). The run above passed first time from this source.

The live service was probed in production on 5 November 2026 with a temporary account (revoked afterwards): English, Chinese and mixed Chinese/English dictation streamed in real time returned the correct transcript 0.6-0.7 s after the audio ended, and a completed Chinese upload returned in 2.1 s.

Remaining limits: the installer is unsigned. This build has only been run on CI runners and in local automated checks, not in everyday use on a real PC. Windows dictation has not been run with a physical microphone against the live service. No live Ask Cadence, live Chat model, physical microphone dictation, S1-mini cleanup on a laptop, fresh real browser sign-in, production-identity installation or real monitor/DPI transitions are certified here. The optional legacy Swift speech capability result is false; it is separate from the shipping dictation path.
