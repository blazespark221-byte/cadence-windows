# Cadence for Windows 1.2.33 — Annotate and Translate work again, and a weekly allowance for the AI features

- **Annotate and Translate work again.** In 1.2.29 they stopped with "Cadence couldn't capture your screen" on every PC. Cadence now captures the screen correctly, including layered windows.
- **A weekly allowance for the AI features.** Chat (including Chat in the notch), Cadence Agent and its spoken replies, Annotate and Translate now share a weekly allowance: 20 requests on Free, 1,000 on Pro (fair use). It resets every Monday at 00:00 UTC.
- **Dictation, dictation cleanup and Refine are unchanged.** They don't count toward this allowance, and their limits stay the same.
- **Clear wording when it runs out.** Chat, Annotate, Translate and Cadence Agent say the weekly allowance is used and when it resets, instead of "Cadence can't help with that message". Cadence Agent stops at once rather than waiting.
- **Settings → Account shows how many you've used this week.**
- 1.2.31 and 1.2.32 weren't published on their own; both are in 1.2.33, along with everything from 1.2.29. The 1.2.30 dictation level-meter fix is a separate line and isn't included.

Includes the required .NET and Swift runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for the exact automated Windows checks and remaining limits.
