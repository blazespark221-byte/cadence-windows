# Cadence for Windows 1.2.6 — dictation in Google Docs

- **Dictation goes into Google Docs again:** in current Chrome and Edge, finishing a dictation in Google Docs ended with “Couldn’t insert text” even with the document focused. Cadence now recognises the page you’re typing in and pastes your words at the cursor. The same fix covers Google Slides and other browser and Electron editors.
- **Text can’t land in the address bar:** if focus moves to the address bar or toolbar before insertion, Cadence stops and keeps your words so you can insert or copy them.
- Includes the weekly dictation allowance on Home from 1.2.5 and the Cadence Agent character from 1.2.4.

Includes the required .NET and Swift runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for the exact automated Windows checks and remaining limits.
