# Cadence for Windows 1.2.46: Cadence Agent removed

- **Cadence Agent is gone:** the Agent page, its request panel and progress card, the Ctrl+Alt+A shortcut, voice conversations and spoken replies, background commands and screen control, and Settings → Connectors have all been removed.
- **Everything else works as before:** dictation, Refine, Styles, Chat, Ask Cadence, Annotate, Translate and the Claude Code sessions in the sidebar are unchanged. Ask Cadence keeps Ctrl+Alt+K and its drafts to paste, but no longer offers to hand a task to the Agent.
- **Your settings, sign-in and chats are kept.** Gmail, Outlook and custom MCP connector sign-ins you added for the Agent are deleted from this PC when 1.2.46 starts.
- **Welcome guide:** the fifth step is now Chat, covering Cadence Chat and Ask Cadence.
- Includes all features from 1.2.45 except Cadence Agent.

Includes the required runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for exact checks and remaining limits.
