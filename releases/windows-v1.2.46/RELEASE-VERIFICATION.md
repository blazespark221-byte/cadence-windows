# Windows 1.2.46 release verification - 30 October 2026

Application and package source: `6491aa9fe6ded304271696e0c1ec1331932c4859` in `blazespark221-byte/cadence`, branch `feature/no-agent-windows`, based on Windows 1.2.45. Build and acceptance: https://github.com/blazespark221-byte/cadence/actions/runs/41018076199 (attempt 1).

This release removes Cadence Agent: the main window's Agent page, its request panel and progress card (notch, edge tab and corner), the Ctrl+Alt+A shortcut and its Settings field, live voice, spoken replies, the background terminal and screen control, the Gmail, Outlook and MCP connectors with Settings > Connectors, the tray entry, the welcome guide's Agent step and the Agent's diagnostics strings. Chat, Ask Cadence, Annotate, Translate, dictation, Refine, Styles and the Claude Code sidebar stay. The Swift/Advanced model choice stays for Chat and Annotate. Ask Cadence keeps Ctrl+Alt+K and its paste-back draft; its offer to hand a task to the Agent is gone, and chats saved with such an offer load with the task as plain reply text. On upgrade, settings containing the Agent's fields load unchanged and the next save drops them. Each launch deletes the Agent's connector sign-ins (`agent-connector:<id>` in the DPAPI secret store) and nothing else; the Cadence sign-in and other files are kept.

Both the Windows shell and Swift bridge were built fresh from clean source on an isolated Windows x64 runner. The package includes matching .NET Desktop/Swift runtimes and Microsoft.ML.OnnxRuntimeGenAI 0.18.0 (with the licences for S1-mini and ONNX Runtime GenAI); the background worker is no longer included. The downloaded ZIP and installer match the build's SHA-256 manifest; 531 payload files were independently verified against build-manifest.json. No application source or customer credentials are included in the public release.

Checks on this revision: 1889 managed-account checks; 119 portable parity checks.

Windows application acceptance: 237 logic/controller checks (0 failures; 1 separate desktop suite skipped), including upgrade checks for old settings, saved chats and the connector sign-in cleanup; 8 Annotate offscreen, 12 Chrome/Edge dictation, 5 opaque-editor, 11 native shortcut and 10 clipboard checks. Exact-package checks: 4 headless gates, 7 floating-control checks, and 16 isolated installer/lifecycle gates, including upgrade from 1.0.4, restart/reinstall, synthetic settings/encrypted-session retention, uninstall and updater handoffs. Verification installers use a separate identity and temporary profiles; the production installation is not changed by these checks. The Agent's native Notepad and background automation steps were removed from CI with the Agent. Locally before the build: all four projects built with 0 warnings and 0 errors; 238 logic and controller offscreen checks (1 skipped); 647 `--offscreen-test` checks; 5 Chat, 8 Annotate and 6 update-prompt offscreen checks; 16 managed controller and 18 billing checks. Locally, one of two known racy parity checks fails intermittently, as it does on the untouched 1.2.45 base; all 119 passed in the CI run above.

Remaining limits: the installer is unsigned. This build has only been run on CI runners and in local automated checks, not in everyday use on a real PC. The upgrade path was checked by the suites above and from 1.0.4, not by updating a real 1.2.45 installation that has used the Agent or its connectors. No live Ask Cadence, live Chat model, live Claude Code session monitoring, physical microphone dictation, Parakeet or S1-mini dictation on a laptop, fresh real browser sign-in, production-identity installation or real monitor/DPI transitions are certified here. The optional legacy Swift speech capability result is false; it is separate from the shipping on-device dictation path.
