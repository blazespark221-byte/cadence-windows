# Cadence for Windows 1.2.0 — Cadence Agent

- **Cadence Agent:** say or type what you want done, such as “Open Word and write a 300-word essay about solar energy” or “Open Edge and search for the weather in Adelaide”. Cadence opens the app, clicks, types and writes for you, and checks each step before reporting back.
- Open it with your own shortcut (Settings → Shortcuts → Cadence Agent), the ✦ button in the floating controls, the tray menu, or Home.
- A small progress card shows each step without taking focus. Press Escape or Stop at any time; reply to continue the conversation.
- Cadence Agent reads the app in front through Windows UI Automation (never screen images or password fields), asks before sending, buying or deleting anything you didn’t request, and stays out of apps you block in Privacy.

Includes the required .NET and Swift runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for the exact automated Windows checks and remaining limits.
