# Cadence for Windows 1.2.4 — meet Cadence Agent's character

- **A new face for Cadence Agent:** a small graphite character with a glowing visor. It glances around and blinks while it waits, looks at you and brightens as you speak, looks up while it thinks, scans and talks while it works in your apps, and smiles when it's done.
- Replaces the animated logo from 1.2.3 in the Cadence Agent window, the voice stage and the progress card.
- Includes faster dictation cleanup from 1.2.2, and Google Docs dictation and direct browser sign-in from 1.2.1.

Includes the required .NET and Swift runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for the exact automated Windows checks and remaining limits.
