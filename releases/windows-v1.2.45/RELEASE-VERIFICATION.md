# Windows 1.2.45 release verification - 29 October 2026

Application and package source: `4f8be1fc356c6edbb315876585459e6c14596800` in `blazespark221-byte/cadence`, branch `release/windows-1.2.45`, based on Windows 1.2.44. Build and acceptance: https://github.com/blazespark221-byte/cadence/actions/runs/40843034128 (attempt 1).

This release adds cleanup & formatting and cleanup on this PC, and opens Chat and Cadence Agent out of the floating controls at every edge. The writing prompt now lays out dictated lists, emails and long messages and follows spoken "new line" and "new paragraph"; the Light gate in the shared Swift engine sends dictations with list, email or layout cues to the writing step instead of finishing them by rule. At Light, English dictation of 150 words or fewer with no spoken layout command can be cleaned up on this PC by S1-mini by Superwhisper (a 0.6B Qwen3 fine-tune trained only for transcript cleanup, Apache 2.0) through ONNX Runtime GenAI 0.18.0 on the CPU. The model (5 files, 406 MB, int4 ONNX export pinned to revision `4231669f` with SHA-256 for every file) downloads after the speech model is ready, only at Light and only on an unmetered connection, and is checked and loaded like the speech model; Settings > Dictation > "Clean up on this PC" (on by default) turns it off and unloads it. Its answer is inserted only when the shared engine accepts it (same sanitizer as the writing service; no added numbers or words beyond the Light limits; a requested list or email actually laid out). When this PC's measured speed predicts more than 1.6 s, when a run passes 3 s, or when an answer is refused, the dictation goes to the writing service as before. Chat, Cadence Agent's request panel and its progress card grow out of the glass tab at a screen edge (DockedPanel); Ask Cadence answers come out of the controls too, and with the controls hidden at an edge still hang from the top of the display the question was asked on.

Both the Windows shell and Swift bridge were built fresh from clean source on an isolated Windows x64 runner. The package includes matching .NET Desktop/Swift runtimes, the self-contained background worker, and Microsoft.ML.OnnxRuntimeGenAI 0.18.0 (with the licences for S1-mini and ONNX Runtime GenAI). The downloaded ZIP and installer match the build's SHA-256 manifest; 535 payload files were independently verified against build-manifest.json.
