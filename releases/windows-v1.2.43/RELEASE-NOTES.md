# Cadence for Windows 1.2.43: Ask Cadence

- **Ask Cadence:** in any app, hold Ctrl+Alt+K and ask out loud, then let go. Cadence Chat answers in the notch without taking you out of your app, and knows which app you asked in and any text you had selected there. Tap the shortcut instead to keep listening until you press it again; press it again while the chat is open to ask a follow-up; Escape cancels. The app’s name, its window title and the selected text are sent with your question; you can remove them before sending, and nothing is read from password fields or apps you’ve blocked. A reply can include a draft for that app, with Paste and Copy, or a task with Run with Cadence Agent. Nothing happens until you click. Change the shortcut in Settings → Shortcuts.
- **Cadence Agent works more like Claude Code.** Each conversation has its own terminal, so the folder carries over from one command to the next, and long-running commands such as servers and watchers keep going in the background, listed with Stop on the Agent page and in the request window. They stop when the conversation ends. When a task needs an app it can’t control another way, the Agent can look at the screen and use the mouse and keyboard as a last resort.
- **Claude Code sessions in the sidebar:** while Claude Code is running on this PC, the Cadence window lists its sessions with Claude’s logo, as Working, Needs you or Idle, with the details on their own page. Nothing is sent anywhere.
- **Names from your Dictionary come out right more often:** Cadence fixes near misses on this PC before cleanup (spacing, hyphens, accents and capitals, and in English, words that sound alike), and cleanup restores Dictionary words that were misheard.
- Dictation messages say Cadence and “the speech model” instead of naming the model.
- Includes all features from 1.2.42.

Includes the required runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for exact checks and remaining limits.
