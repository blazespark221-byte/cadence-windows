# Windows 1.2.43 release verification - 28 October 2026

Application and package source: `c9877e1831e5f3276decd99d25301939b7cdcf4a` in `blazespark221-byte/cadence`, branch `release/windows-1.2.43`, based on Windows 1.2.42. Build and acceptance: https://github.com/blazespark221-byte/cadence/actions/runs/40688644745 (attempt 1).

This release adds Ask Cadence: holding Ctrl+Alt+K records a spoken question, which is transcribed on this PC and sent to Cadence Chat in the notch together with the app's name, its window title and any selected text. Selection is read through UI Automation first, then with one verified Ctrl+C when the clipboard fallback is allowed (never in terminals). Password fields and blocked apps send nothing, and the context can be removed before sending. Replies can offer a draft with Paste and Copy, or a task with Run with Cadence Agent; nothing runs without a click. Ctrl+Alt+A stays Cadence Agent's shortcut. Cadence Agent now works terminal first: one terminal per conversation keeps its working folder, long commands continue as background commands listed with Stop, and screen control returns as a last resort. The sidebar lists running Claude Code sessions, read locally from Claude Code's session files, with Claude's official spark logo. Dictionary terms are corrected on this PC before cleanup, and dictation messages no longer name the on-device speech model.

Both the Windows shell and Swift bridge were built fresh from clean source on an isolated Windows x64 runner. The package includes matching .NET Desktop/Swift runtimes and the self-contained background worker.
