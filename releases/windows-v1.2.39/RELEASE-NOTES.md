# Cadence for Windows 1.2.39 — the same controls at every screen edge

- **The same controls wherever you put them.** With the controls at the bottom, left, top or right of the screen, hovering the glass tab now opens the same black panel as the notch, with the same actions: Dictate, Rewrite, Chat, Annotate, Translate, Cadence Agent, Cleanup, Style, Play sounds, Position, Settings and Hide. It springs out of the tab the way the notch panel springs out of the notch. Before, those positions opened an older row of small symbol buttons. Closed, the controls are still the glass tab.
- Includes everything from 1.2.38.

Includes the required .NET and Swift runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for the exact automated Windows checks and remaining limits.
