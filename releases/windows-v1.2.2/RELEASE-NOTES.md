# Cadence for Windows 1.2.2 — faster dictation cleanup

- **Cleanup arrives much sooner:** Cadence's service now checks your account while it cleans up your dictation, instead of before it starts, so cleaned-up text reaches your app much sooner after you stop speaking.
- **No wait when there's nothing to clean:** with Light cleanup, short dictation that has no filler words, repeats or spoken corrections ("no, Tuesday") is inserted immediately, just like with cleanup off. Medium still polishes every dictation.
- Includes Google Docs dictation and direct browser sign-in from 1.2.1.

Includes the required .NET and Swift runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for the exact automated Windows checks and remaining limits.
