# Cadence for Windows 1.2.19 — Cadence Agent stays in the Cadence window

- **Cadence Agent stays in the Cadence window.** A request typed or spoken on the Agent page used to hide the window and open a separate Agent pop-up. Now the conversation stays on the page: what you asked, each step as it happens and the answer, with the full chat box (files, Manual or Full access, dictation and voice mode) underneath. The agent still clicks and types in the app it works in, which comes to the front while it acts. Cadence comes back to the front only when it needs your OK in Manual mode or asks you a question. **New conversation** starts over. The shortcut, notch, tray and floating controls still open the Agent's own panel.
- **Cadence moves into the notch.** If you already use Cadence, your controls move into the notch at the top centre of the screen once, as on a Mac. To put them somewhere else, choose another position under Settings → General → Floating control position. Cadence keeps that choice.
- **Rounded Refine buttons.** Refine's Rewrite, Presets, Add file and Copy buttons have rounded corners like on the Mac. Hovering over them now shows a soft highlight instead of blue.
- Includes the sign-in changes from 1.2.18 and 1.2.17, the stuck-key shortcut fix from 1.2.16, dictation with a picture on your clipboard from 1.2.15 and dictation at the cursor from 1.2.14.

Includes the required .NET and Swift runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for the exact automated Windows checks and remaining limits.
