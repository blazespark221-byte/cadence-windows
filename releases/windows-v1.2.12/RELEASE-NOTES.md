# Cadence for Windows 1.2.12 — talk with Cadence Agent

- **Talk with Cadence Agent:** the Agent opens in voice mode and talks back, like a voice assistant. It says what it's doing ("Opening Word.") and answers out loud, then keeps listening, so you can keep the conversation going hands-free. Just start talking while it speaks to interrupt it. Turn spoken replies off with the speaker button.
- **New Agent layout:** the Agent's character sits on top and is bigger, with the conversation and the chat box underneath. Steps read as a clean list instead of icons.
- **New chat box:** attach files with **+**, choose **Manual** (Cadence asks before each click or keystroke) or **Full access**, use the mic to dictate into the box, or the white button for voice mode.
- **Agent page** in the main Cadence window, with ideas to try and the Agent's shortcut.
- Fixes an "HTTP 502" error when the Agent tried to write the same text repeatedly.
- Includes faster dictation from 1.2.11 and Chat with Cadence from 1.2.10.

Includes the required .NET and Swift runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for the exact automated Windows checks and remaining limits.
