Windows 1.0.6 keeps updates within reach:

- Check for updates is fixed at the bottom left of the main window and every Settings page, including Home, Dictionary and Account.
- Available versions stand out in the sidebar, with Download update, progress, cancellation and Restart & Update in the same place.
- About retains automatic-check and prerelease preferences. Update actions no longer require opening About or scrolling a page.
- Light/dark themes and minimum window sizes retain a visible update action.

Windows 10 build 19041+ on Intel/AMD x64. Existing preferences and sign-in are retained. This release is unsigned. See RELEASE-VERIFICATION.md for checks and limits.
