# Cadence for Windows 1.2.42: models in Chat

- Choose Cadence Chat's model from the new menu next to Attach, in the Chat window and the notch chat: **Swift**, the default on every plan, or **Advanced** on Pro. Chat remembers its choice separately from Cadence Agent's, and a chat started from Annotate uses it too.
- Cadence Agent's models are now called Swift and Advanced as well. On Free, choosing Advanced explains that it needs Pro and keeps Swift.
- A new look for the Agent request box: the model and access menus sit on the left with small arrows, and Attach sits on the right beside dictation and Send.
- Cadence Agent always works in the background, so the **Work in background** switch is gone. Manual mode still asks before commands and control changes, and Stop still cancels.
- Includes all features from 1.2.41 and 1.2.40, including on-device Parakeet dictation.

Includes the required runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for exact checks and remaining limits.
