# Cadence for Windows 1.2.3 — Cadence Agent comes alive

- **The Cadence logo responds as you talk to the agent:** it swells with your voice and sends out ripples while it listens, light glides across it while it works out your request and operates your apps, and it blooms when it finishes.
- **Speak a request and the logo takes centre stage** in the Cadence Agent window; the progress card's logo shows the agent at work.
- Includes faster dictation cleanup from 1.2.2, and Google Docs dictation and direct browser sign-in from 1.2.1.

Includes the required .NET and Swift runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for the exact automated Windows checks and remaining limits.
