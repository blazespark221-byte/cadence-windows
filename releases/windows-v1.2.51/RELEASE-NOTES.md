# Cadence for Windows 1.2.51: your shortcuts keep working when another app takes one

- **When another app already uses one of Cadence's shortcuts, your other shortcuts keep working.** Before, if another app had taken Refine's key combination, dictation stopped too (even on Right Alt), and every new dictation shortcut you chose was refused with "this shortcut is already in use".
- **Cadence names the shortcut that's taken.** Settings → Shortcuts says which one another app owns, for example "Refine's shortcut, Ctrl + Alt + R, is already used by another app", so you can choose a different one. Cadence tries it again the next time it starts or you change a shortcut.
- Your settings, sign-in, History and chats are kept. Includes all features from 1.2.50.

Includes the required runtimes. The installer is unsigned. See RELEASE-VERIFICATION.md for exact checks and remaining limits.
