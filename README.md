# Cadence for Windows

Speak to insert text at your cursor, or select text, ask for a rewrite, review and replace it.

[Download Windows 1.2.2](https://github.com/blazespark221-byte/cadence-windows/releases/download/windows-v1.2.2/Cadence-1.2.2-windows-x64-setup.exe) · [Portable ZIP](https://github.com/blazespark221-byte/cadence-windows/releases/download/windows-v1.2.2/Cadence-1.2.2-windows-x64-portable.zip)

**New in 1.2.2:** cleaned-up dictation arrives much sooner, and with Light cleanup, dictation that has nothing to clean up is inserted immediately. Includes Google Docs dictation and direct browser sign-in from 1.2.1.

**Cadence Agent:** say or type what you want done, such as “Open Word and write a 300-word essay about solar energy”, and Cadence opens the app, clicks, types and writes for you, checking each step. Open it with your own shortcut (Settings → Shortcuts), the ✦ floating control, the tray menu or Home. Escape or Stop ends the task at any time.

Sign in from the setup guide, which opens your browser, or from Settings → Account. Required runtimes are included. Windows 10 version 2004+ and Windows 11 x64. Hold Ctrl+Alt+Space to dictate; release to insert. Select text and press Ctrl+Alt+R to review a rewrite. Escape cancels. Upgrades preserve your preferences.

Includes live dictation, Cadence Agent, the daily dashboard graph, floating quick controls and in-app updates. Your account provides the managed speech and writing connection.

The installer is unsigned. Windows may show an unknown-publisher or reputation prompt. See the [verification record](releases/windows-v1.2.2/RELEASE-VERIFICATION.md) for the exact automated checks and remaining limits.
