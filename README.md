# Cadence for Windows

Speak to insert text at your cursor, or select text, ask for a rewrite, review and replace it.

[Download Windows 1.2.16](https://github.com/blazespark221-byte/cadence-windows/releases/download/windows-v1.2.16/Cadence-1.2.16-windows-x64-setup.exe) · [Portable ZIP](https://github.com/blazespark221-byte/cadence-windows/releases/download/windows-v1.2.16/Cadence-1.2.16-windows-x64-portable.zip)

**New in 1.2.16:** a stuck key can’t switch off your shortcut. If another app loses a key release, Windows can report a key such as F9 as held for hours, and a lone Right Alt (or Ctrl, Shift or Alt) shortcut then did nothing. Cadence now ignores a key that has stopped sending input, and Settings → Diagnostics explains an ignored press. Includes dictation with a picture on your clipboard from 1.2.15, dictation at the cursor from 1.2.14, Cadence in the notch by default from 1.2.13, talking with Cadence Agent from 1.2.12 and faster dictation from 1.2.11.

**Cadence Agent:** say or type what you want done, such as “Open Word and write a 300-word essay about solar energy”, and Cadence opens the app, clicks, types and writes for you, checking each step. Open it with your own shortcut (Settings → Shortcuts), the ✦ floating control, the tray menu or Home. Escape or Stop ends the task at any time.

Sign in from the setup guide, which opens your browser, or from Settings → Account. Required runtimes are included. Windows 10 version 2004+ and Windows 11 x64. Hold Ctrl+Alt+Space to dictate; release to insert. Select text and press Ctrl+Alt+R to review a rewrite. Escape cancels. Upgrades preserve your preferences.

Includes live dictation, Cadence Agent, the daily dashboard graph, floating quick controls and in-app updates. Your account provides the managed speech and writing connection.

The installer is unsigned. Windows may show an unknown-publisher or reputation prompt. See the [verification record](releases/windows-v1.2.16/RELEASE-VERIFICATION.md) for the exact automated checks and remaining limits.
