# Cadence for Windows

Speak to insert text at your cursor, or select text, ask for a rewrite, review and replace it.

[Download Cadence.exe](https://github.com/blazespark221-byte/cadence-windows/releases/download/windows-v1.0.3/Cadence.exe) · [Portable ZIP](https://github.com/blazespark221-byte/cadence-windows/releases/download/windows-v1.0.3/Cadence.zip)

Open Settings → General → Sign in to Cadence. Your account includes the connection for
speech and writing; no personal provider configuration or separate Codex installation is required.
Required runtimes are included. Windows 10 version 2004+ and Windows 11 x64.

Hold Ctrl+Alt+Space to dictate; release to insert. Select text and press Ctrl+Alt+R to
review a rewrite. Escape cancels. Upgrades preserve your preferences.

The installer is unsigned. Microsoft Defender scanning passed for these exact bytes,
but SmartScreen may still show an unknown-publisher/reputation warning.
Read the [verification record](releases/windows-v1.0.3/VERIFICATION.md) for executed checks
and remaining browser, microphone and external-editor acceptance limits.
